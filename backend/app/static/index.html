Idempotent Ingestion

Every job payload can carry a unique idempotency_key. Submitting the identical request multiple times safely returns the existing job record without re-enqueuing.

Distributed Leases

When a worker dequeues a task, it sets an exclusive Redis key job:lease:<id> with a 30s TTL. If a worker container crashes mid-execution, the Reaper automatically detects lease expiry and reclaims the task.

Exponential Backoff

Transient failures are scheduled into a sorted set with dynamic backoff delay: Delay = base * 2^(retry-1) + jitter. Once retries exceed bounds, tasks enter Dead-Letter Quarantine.

from sdk.python.jobqueue import JobQueue

# Initialize client
queue = JobQueue(base_url="http://127.0.0.1:8000")

# Dispatch background task asynchronously in ~20ms!
job = queue.dispatch(
    job_type="email_dispatch",
    priority="high",
    payload={"to": "customer@gmail.com", "subject": "Order #4092 Shipped!"}
)
print("Enqueued background job:", job["id"])
